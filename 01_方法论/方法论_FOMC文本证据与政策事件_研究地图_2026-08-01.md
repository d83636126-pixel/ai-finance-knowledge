## 五、思想 → 指导映射（按项目批次）

### 5.1 对当前契约（A1）直接指导

| 思想 | 对项目的指导 |
|---|---|
| **GKT《Text as Data》可复现性** | 身份绑定 + 段落归一化 + SHA-256 + 可回放契约 = 文本即数据可复现性纪律的代码化；预处理选择（CRLF/LF、段落切分）必须文档化且确定性可审计 |
| **Cieslak & Schrimpf 非货币信息** | 为不变量 #4 背书：文本→市场不能证明政策立场；是"禁止输出因果鹰鸽分数"的文献支柱 |
| **Doh–Song–Yang tone × novelty** | 立场 = 绝对语气 × 相对上一期的变化；验证 `text_changes`（batch B）独立成批、不进 canonical bundle 的设计 |
| **2026 novelty 派（Siklos 组 / PLMIS）** | 增量信息（相对前文的新意）才是有效分析单位；bundle 只配对 current/prior 是正确粒度，batch B 应暴露段落级 diff |

### 5.2 对后续批次（batch B/C、A2）的指导

| 思想 | 落在哪个批次 |
|---|---|
| **Loughran–McDonald / Tetlock 词典式立场** | batch C：可审计词典立场作 fail-safe 基线层，每句立场指回原文段落；LLM 概率分作第二层 |
| **Tang–Yang DCS（delta-consistency）** | batch C：建模"绝对立场+跨会议偏移"，免标注自监督；市场验证部分不采用 |
| **FEDS Fine-Tune / BoC 语调工具** | batch A2：新闻发布会纪要应作独立文档类型纳入 source coverage，证据价值与声明不同 |
| **Aruoba–Drechsel 残差法** | batch C（远期）："新信息=实际与预期之差"的测量思路，但需先有立场预测模型 |

### 5.3 作为禁止线的引用（不照做）

| 思想 | 为何不照做 |
|---|---|
| **Romer–Romer / Nakamura–Steinsson / Bernanke–Kuttner** | 定义"政策冲击"需高频率期货/市场数据做残差；本项目明确不做文本→市场因果。写边界理由时引用 Cieslak–Schrimpf 即可 |

## 六、2026 沃什沟通体制对项目的现实冲击

2026-05 新主席 **Kevin Warsh** 上任后大幅压缩声明（6 月声明约 130 词，砍掉前瞻指引和投票明细）：

1. **段落归一化与 `text_changes`（batch B）**：长声明时代的 fixture 不构成新常态；段落 schema 须能处理短声明，否则段落 ID 稳定性被打破。
2. **`source_version` 语义**：声明长度/结构变化本身就是版本信号；版本键（source_version + document hash）正好能捕捉体制切换。
3. **鹰鸽解读（batch C）**：2026 论文普遍结论"相对上一期偏移比绝对立场更重要"，与不变量 #4（不用文本变化证明因果）吻合——立场测量可存在，但不可当因果用。

## 七、最该先读的三个

1. **Cieslak & Schrimpf（2019）**——不变量 #4 的文献支柱；
2. **Doh–Song–Yang（AEJ:Macro 2026）**——tone×novelty 分解，直接映射 bundle 设计；
3. **Warsh 时代声明压缩 + FEDS Fine-Tune**——fixture 段落 schema 要能处理 130 词短声明，当下就要做的现实修正。
