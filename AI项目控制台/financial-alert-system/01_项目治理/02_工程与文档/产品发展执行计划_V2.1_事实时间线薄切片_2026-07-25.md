# 产品发展执行计划 V2.1：事实时间线薄切片

本页补丁 **V2**（事件研究工作台），不废止事件类型愿景，但**重写本阶段验收与主路径**。

## 1. 问题陈述

V2 批次实现偏「结构化研究卡全量 UI」，对使用者实际用途存疑：录入成本高、系统增益低、离开页面缺少可执行产出。

## 2. 本阶段唯一主任务

对已发生或窗口中的事件：最少输入 → **事实时间线** → **自动观察清单**（可勾选）；判断可选。

## 3. 验收

- 采用：`EVENT_FACT_TIMELINE_V1_PASS`
- **不采用**本阶段目标：`EVENT_RESEARCH_WORKSPACE_V1_PASS`
- 仍不宣称：`RESEARCH_PASS` / `HELD_OUT_PASS` / `LIVE_FORWARD_PASS`

### 完成标准

1. 无需编辑内部文件即可创建事件并添加事实；
2. 事实带时间戳与来源（默认手工录入）；
3. 可生成并保存观察清单勾选状态；
4. 可复制一页摘要；
5. 判断非必填；
6. demo / 手工数据有标注。

### 本阶段明确不做

- 完整判断 IDE 作为主路径
- 财报全模板作为主路径
- 版本 diff / 复盘长表单作为主路径
- UW 八模式合流
- 旧 V1 集中 Codex R1（待 Human 确认薄切片后再议）

## 4. 与 V2 的关系

| V2 章节 | V2.1 处理 |
|---|---|
| §6–11 全量阶段 | 延后；代码可保留在「高级」折叠 |
| §13 `EVENT_RESEARCH_WORKSPACE_V1_PASS` | 本阶段停用为成功标准 |
| §14 审核规则 | 薄切片齐套且 Human 确认后再定是否 R1 |
