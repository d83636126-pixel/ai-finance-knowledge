## 3. 硬原则

1. 复用 `event_id`；纳入研究必须幂等。  
2. 研究详情只做统一编排，不重写传播/判断引擎。  
3. `localStorage` 仅缓存；真相源为服务端 registry。  
4. 保留 `event_research_workspace`，停止扩展独立表单与通用观察问句。  
5. 未来/未解锁历史禁止事后报告（逻辑+UI+负向验证）。  
6. 完整 V1 后才交 Codex 集中 R1。

3. **第三切片**：AnalysisResults 合流索引 + 正式事后入口 + 重开增量（`last_opened_at` / 相对变化）  
4. **第四切片**：对比合流 + 日历已纳入态 + 深链回跳  
5. **第五切片**：V1_READY 证据齐套（入口 + 结果过滤 + Human 清单 + 聚合烟雾；不宣称 PASS）
